# Deepspot Desktop

Official installers for the **Deepspot** desktop app.

Deepspot Desktop opens the Deepspot platform in its own window, so it is always on the latest version — no manual updates needed.

## Installation — Windows

1. Download **Deepspot-Setup-x64.exe**.
2. Double-click the file to start the installer.
3. If Windows shows *"Windows protected your PC"*, select **More info → Run anyway**.
4. Follow the installer, then open **Deepspot** from the Start menu and sign in.

**Silent install (IT administrators):**

```powershell
msiexec /i Deepspot-x64.msi /qn
```

## Uninstall

**Settings → Apps → Installed apps → Deepspot → Uninstall**
